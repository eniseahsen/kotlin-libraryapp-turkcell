# Library App

Library App is a modern Android application where users can browse books, borrow and return them; additionally, admin users can manage books.

The application is developed using **Jetpack Compose, MVVM architecture, and Supabase backend**.

## Technologies Used

- Kotlin
- Jetpack Compose
- MVVM Architecture
- Kotlin Coroutines
- StateFlow
- Supabase
- Navigation Compose

## Architecture

The application uses a layered architecture:

- UI (Compose Screens)
- ViewModel
- Repository
- Supabase (Backend)
