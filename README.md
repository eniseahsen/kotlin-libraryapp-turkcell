# Library App
Library App, kullanıcıların kitapları görüntüleyebildiği, ödünç alabildiği ve iade edebildiği; ayrıca admin kullanıcıların kitap yönetimi yapabildiği modern bir Android uygulamasıdır.

Uygulama **Jetpack Compose, MVVM mimarisi ve Supabase backend** kullanılarak geliştirilmiştir.

## Kullanılan Teknolojiler
- Kotlin
- Jetpack Compose
- MVVM Architecture
- Kotlin Coroutines
StateFlow
- Supabase (Auth + PostgREST)
- Navigation Compose

## Mimari Yapı
Uygulama katmanlı bir mimari kullanır:
- UI (Compose Screens)
        
- ViewModel
        
- Repository
        
- Supabase (Backend)
